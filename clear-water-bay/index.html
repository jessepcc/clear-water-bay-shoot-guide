X‑T5 现场速查

Fujinon XF 23mm F1.4 + Viltrox AF 75mm F1.2。先选场景，再照着「站位 → 口令 → 参数」拍；参数是起点，以现场光线与回放为准。

开拍前 · 60 秒
  • RAW + FINE JPEG；机械快门；CL 先用 5–7 fps；IBIS 开。X‑T5 没有内置闪光灯，这套器材先用自然光。
  • M 档 + Auto ISO：固定下表的光圈与快门，ISO 自动 125–3200。静态用 AF‑S 单点；走动用 AF‑C 区域，脸部 / 眼睛检测开。人物眼睛检测与动物等「主体检测」是不同菜单。
  • 看直方图 / 高光闪烁：测光预设多重；眼检测开启时以脸部检测参与曝光，手动测光模式需关闭脸 / 眼与主体检测才生效。曝光补偿从 0 开始，以脸部和白裙都保留细节为准。逆光可试 +⅓ EV，白裙闪烁就往回减。脸 / 眼检测开启时，不要依赖点测光切换作为曝光捷径。
  • Astia / Soft；白平衡先用 Auto。同一组光线锁定日光或固定 K 值，避免连拍每张颜色跳动。开拍先让模特站好，拍一张测试肤色。
  • DR100 → ISO 125 起；DR200 → ISO 250 起；DR400 → ISO 500 起。动态范围档位不能恢复已剪切的高光；先正确曝光，再调整 JPEG 高光与阴影。

23mm · 人与地方

视角约等效 35mm。全身、海岸、草坡、走动组图用它。站约 2–4m；让脸离画面边缘远一点，镜头保持接近腰胸高度。环境人像从 f/2.8–4 开始。

75mm · 表情与光

视角约等效 112.5mm。半身、发丝、干净背景用它。半身站约 4–6m；全身约 8–12m，预留说话空间。先用 f/1.8–2；f/1.2 留给静态、单眼清晰的特写。

海滩走动 · 二滩浪线

23mm · f/41/1000sAuto ISO
站位
与她保持约 3m，沿浪线平行移动。太阳在你侧后方，海平线避开脖颈。
口令
「慢慢走三步，看远处；下一遍回头看我。」动作分两次拍。
对焦
AF‑C + 区域 + 眼检测；短连拍。对焦框跟上后再按快门。
色彩
Astia；日光 WB；DR200 / ISO ≥250；高光 −1、阴影 0、色彩 0。
检查
放大眼睛与裙摆，白裙不过曝。背景太挤：等空档或换 75mm f/2，别靠开放光圈解决全部问题。

礁石静坐 · 一滩干燥、安全的岩石

75mm · f/21/500sAuto ISO
站位
离她约 4–6m，找同一水平的机位。侧面柔光，海在远处，避免正午硬阴影。
口令
「侧坐一点，肩放松，手轻放膝盖；先看海，再只转眼睛。」
对焦
AF‑S 单点 + 眼检测；优先近侧眼。她开始回头时切 AF‑C。
色彩
Pro Neg. Std；阴天 WB；DR100；高光 −1、阴影 0。保留岩石与皮肤的自然色差。
检查
裁切别落在关节；脸太暗先换方向。模特与摄影者都留在干燥岩石内侧。

草坡全身 · 大坑墩开阔绿坡

23mm · f/2.8–41/500sAuto ISO
站位
约 3m，机位在她腰部高度。前景少量草、人物、远景大树三层；找干净边缘，别让树干穿过头。
口令
「拿着草帽慢走，看右边；停一下，身体不动，回头。」不摘公园植物。
对焦
走动 AF‑C；停下 AF‑S。草遮住脸时把对焦点移到眼睛，别让相机锁前景。
色彩
Astia 或 Classic Chrome；日光 WB；DR200 / ISO ≥250；高光 −1、阴影 0。面部偏绿就换个离草反光更远的位置。
检查
脸放画面中央区域；人占画面 ⅓–½，先拍有场景的全身，再换 75mm 收表情。

逆光半身 · 大坑墩傍晚

75mm · f/1.8–21/1000sAuto ISO
站位
约 4–6m，太阳藏在她头部或树干后；用手或遮光罩挡侧面杂光。找天空能照亮脸的位置。
口令
「身体转 45°，下巴稍微往前，再放松；等风来，看我一下。」
对焦
AF‑C + 眼检测；静止可用 AF‑S。强逆光识别失败时，把单点放在近眼。
色彩
Astia；日光 WB（约 5200–5600K 起）；DR200 / ISO ≥250；高光 −1、阴影 −1。固定 WB 后再拍整组。
检查
曝光 0 → +⅓ EV 试拍；白裙与脸不闪烁。脸太暗用现有浅色地面反光或换站位；别直接加到 +1 EV。

阴天近景 · 海滩 / 草坡皆可

75mm · f/1.81/500sAuto ISO
站位
约 3–4m，脸朝向最亮的一侧天空；背景离模特远一些。避开树下绿色反光。
口令
「摸一下头发，低头笑；抬眼看我，手先不要动。」一张眼神、一张自然动作。
对焦
静态 AF‑S；动作 AF‑C。f/1.2 只在模特静止、眼睛放大确认后尝试。
色彩
Pro Neg. Std 或 Astia；阴天 WB / 约 6000K 起；DR100；高光 −1、阴影 0、色彩 0。
检查
ISO 到上限仍偏暗：静态才把快门降至 1/250s；走动保持 1/500s，必要时允许更高 ISO。IBIS 不能冻结人物动作。
⚡ 参数不对时，先改哪一个？
  • 明亮沙滩 f/1.2 太亮：X‑T5 机械快门最快 1/8000s。先降 ISO（DR100 可到125），再收光圈；继续全开需要 ND。电子快门有运动变形和某些光源下的条纹风险。
  • 眼睛虚、耳朵清楚：f/1.2 景深很薄。先收至 f/2、确认近眼、拍完放大；别把 IBIS 当动作防抖。
  • 白裙全白、脸正常：曝光补偿 −⅓ EV 再检查高光。RAW 可以后期提脸，已经剪切的高光不一定能救。
  • 背景人多：换机位 / 等空档 → 75mm 拉远背景 → f/2；不要站在拥挤通道里倒退拍摄。
  • 想要闪光的社媒效果：需额外热靴闪光灯，这套器材没有。自然光拍法已经足够；无需为直闪效果改变当日拍摄计划。

一组 6 张 · 两支镜头就够

23mm：① 场景全身 ② 走动回头 ③ 坐姿环境。75mm：④ 半身眼神 ⑤ 头发 / 手部动作 ⑥ 风吹时自然笑。先完成 6 张，再换衣服或地点。发布时裁 4:5，拍摄保留头顶、脚下与两侧空间。

大坑墩风筝场无更衣室草坡开阔

🌾 大坑墩（清水湾郊野公园内）

  • 长什么样：一片开阔的绿色草坡 + 几棵标志性大树，远处能望到海。注意：10月初先按绿草坡准备，不要为了芒草海改变路线；现场以实际植被为准。
  • 怎么去（下午场）：从海滩乘九巴91 / 小巴103、103M往市区方向，在「大坳门」下车，沿清水湾道上斜步行约15–20分钟。
  • 换装：建议在海滩更衣设施开放时先换好第二套；郊野草坡不作为换装点。带足饮水，别依赖小食亭营业。
  • 拍什么：① 逆光发丝（16:30后，太阳低了才有）；② 蹲低用75mm把人从草坡里"拔"出来，前景留虚化的草做框；③ 大树下借鉴《可憐》的柔光与枝叶框景；④ 23mm拍大环境，人在草坡上只占一小块。
  • 注意：周六放风筝、野餐的人多，取景避开人群或用大虚化藏掉；草坡无遮阴，防晒做足。

一滩 · 人少礁石

🌊 清水湾第一湾（一滩 / 细清水）

  • 长什么样：比二滩小、安静，滩边混着大礁石和石滩——岩石质感人像首选。
  • 怎么去（上午第一站）：九巴91（钻石山站 ↔ 清水湾）在「清水湾第一滩」站下车即达；或乘小巴103到二滩，再沿海滨步道走15分钟过来。
  • 准备：更衣、淋浴与洗手间请现场确认开放情况；自带水和零食。带鞋走台阶与石滩，别赤脚搬器材。
  • 浪线拍摄：先看泳滩开放、水质公告和旗号；不合适就留在干沙拍走动，不以往年评级决定当天是否下水。
  • 拍什么：礁石区坐拍 / 站拍（参考AI概念图③）；早上9点人最少，背景最干净。

二滩 · 沙细热带

🌊 清水湾第二湾（二滩 / 大清水）

  • 长什么样：沙滩最大、沙最细，背后是整片绿山——经典"热带天堂"构图，右侧滩头有石滩。
  • 怎么去：小巴103（观塘码头线）直达「清水湾第二湾泳滩」总站；103M（将军澳站线）也到；九巴91坐到「清水湾」总站再步行前往。
  • 设施：小食亭、更衣室等齐全，人流也是三个点里最多的。
  • 浪线拍摄：水质和开放情况出发前另查；遇大浪或关闭公告，改拍干沙上的走动与回头。
  • 拍什么：23mm大场景（人+沙滩+绿山）；白裙踏浪；人多时用75mm长焦虚化掉背景人群。

两滩之间有岩石岬角 + 约15分钟步道相连，约100级台阶，轻装上阵。

给新手的建议

  • 每个点只练3–4个 pose。 概念图①–⑥每张就是一个机位，拍透比拍多重要。
  • 让她动起来。 "往前走""玩头发""先看远再回头"——动态比摆拍自然十倍，快门连拍。
  • 你先示范。 把手机概念图举给她看，自己松弛地比划一下，尴尬减半。
  • 多夸，具体夸。 "这个回头特别好""风把裙子吹起来了完美"——模特放松了才有好表情。
  • 逆光记得给脸补曝光。 先看脸的受光方向，再从 0 到 +⅓ EV 试拍；检查白裙高光，避免盲目加曝光。
  • 带的东西：水、防晒、草帽（道具）、小风扇、湿纸巾、拉链袋、充电宝。
