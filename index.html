实地情报

查过资料、核对过设施——到现场不会踩坑的那种。

大坑墩风筝场无更衣室无遮阴

🌾 大坑墩（清水湾郊野公园内）

  • 长什么样：一片开阔的绿色草坡 + 几棵标志性大树，远处能望到海。注意：10月初芒草季还没到（芒草11–12月才盛），别期待芒草海，绿草坡 + 逆光一样出片。
  • 怎么去：九巴91 / 小巴16、103、103M 在「大坳门」下车，沿清水湾道上斜步行约15–20分钟。
  • 设施：有烧烤场和小食亭；没有更衣室，第二套衣服提前换好或车上换。
  • 拍什么：① 逆光发丝（16:30后，太阳低了才有）；② 蹲低用75mm把人从草坡里"拔"出来，前景留虚化的草做框；③ 大树下拍滨田英明式仰拍；④ 23mm拍大环境，人在草坡上只占一小块。
  • 注意：周六放风筝、野餐的人多，取景避开人群或用大虚化藏掉；草坡无遮阴，防晒做足。

一滩 · 人少礁石

🌊 清水湾第一湾（一滩 / 细清水）

  • 长什么样：比二滩小、安静，滩边混着大礁石和石滩——岩石质感人像首选。
  • 设施（已核对）：停车位、小食亭、烧烤场、更衣室、淋浴、洗手间、浮台。自带水和零食更稳。
  • 水质：环保署2025年评级为「一般」，下水玩玩可以，拍完记得冲洗。
  • 拍什么：礁石区坐拍 / 站拍（参考AI概念图③）；早上9点人最少，背景最干净。

二滩 · 沙细热带

🌊 清水湾第二湾（二滩 / 大清水）

  • 长什么样：沙滩最大、沙最细，背后是整片绿山——经典"热带天堂"构图，右侧滩头有石滩。
  • 设施：小食亭、更衣室等齐全，人流也是三个点里最多的。
  • 水质：环保署2025年评级为「良好」。
  • 拍什么：23mm大场景（人+沙滩+绿山）；白裙踏浪；人多时用75mm长焦虚化掉背景人群。

两滩之间有岩石岬角 + 约15分钟步道相连，约100级台阶，轻装上阵。

① 草坡逆光剪影

② 草丛低角度回头

滨田英明式机位：你蹲到草里仰拍，前景的草虚化成天然画框。模特戴草帽、回头——新手最不尴尬的pose。

拍法：75mm f/1.4，你蹲低 / 趴低。让模特先看远方，你喊"回头"再连拍。

③ 草原大环境

换上23mm，人只占画面一小块——"地方感"拉满。这种图和特写拼在一起，组图才有呼吸感（川内伦子式思路）。

拍法：23mm f/4–f/5.6，把人放在三分线上。云多的时候天空最有戏。
AI概念图 一滩 · 礁石区
④ 礁石静坐

一滩礁石区的标准答案：白裙坐礁石上，不看镜头。阴天来拍反而更好——云是天然柔光箱，岩石质感更沉。

拍法：75mm f/2，Pro Neg Std（阴天）/ Astia（晴天）。注意脚下湿滑，别让模特站太边缘。
AI概念图 二滩 · 热带沙滩
⑤ 踏浪行走

二滩招牌：细沙 + 绿山 + 白裙。让模特沿着浪线走，你横向跟拍连拍——走起来的裙摆比任何摆拍都自然。

拍法：23mm f/4 大场景；想虚化掉人群换75mm。白沙会骗测光，+0.7EV起步。
AI概念图 海滩 · 逆光特写
⑥ 逆光发丝特写

把太阳藏在模特脑后，发丝会透出光边。这是滨田英明最爱的光线语言——脸不需要亮，轮廓亮就够了。

拍法：75mm f/1.2，点测脸部 +0.3EV（脸允许稍暗）。傍晚或清晨才有这个角度。

通用设置
  • 画质：RAW + JPEG Fine（胶片模拟直出，RAW 兜底）
  • 对焦：AF-C + 广域/跟踪 + 人眼识别开

濱田英明 Hideaki Hamada · 1977–

拆的这张：两个孩子坐在大树上，仰拍，阳光透过树叶洒成光斑，孩子望向远方不看镜头（Lomography 专访配图，Pentax 67II 胶片拍摄）。

🔍 拆解

  • 光线：午后树荫下的斑驳逆光/顶光，背景树叶过曝成圆形光斑，人物脸在柔和阴影里。
  • 构图：低角度仰拍，粗树干当前景框住人物；人物不看镜头，"被观察的生活感"。
  • 色彩：暖黄绿胶片调，低对比，暗部不死黑——典型的 Portra 式温柔。
富士配方 · 滨田式逆光
胶片模拟 Astia｜白平衡 5600K，R+2 / B−2（偏暖）
高光 −1｜阴影 +1｜色彩 +1｜颗粒 弱｜DR200
曝光 +0.7EV（让背景"烧"出光斑）｜75mm f/1.2 全开
📍 清水湾复刻：大坑墩巨树下。你蹲低/趴低仰拍，让模特坐草坡上或靠树干，先看远方再随意转头——连拍抓"没在摆"的瞬间。

篠山紀信 Kishin Shinoyama · 1940–2024

拆的这张：《Double Fantasy》专辑封面——1980年中央公园，列侬与洋子接吻。户外自然光，黑白，高反差，颗粒粗粝，情绪压过一切技术。

🔍 拆解

  • 光线：户外自然光（阴天般的柔和），面部受光均匀，没有戏剧性布光——情绪全靠瞬间。
  • 构图：贴得很近，头肩裁切，亲密感拉满；不追求"美"，追求"真"。
  • 影调：黑白，深黑、高反差、明显颗粒——"激写 Gekisha"式的直接有力。
富士配方 · 筱山式黑白
胶片模拟 ACROS（+R 滤镜，皮肤更通透）
高光 +2｜阴影 +2｜颗粒 强｜锐度 +1
曝光 0EV（相信机测光）｜75mm f/2，连拍抓瞬间
📍 清水湾复刻：海滩上别只摆拍——让模特闭眼、笑、被风吹乱头发，你用ACROS连拍。情绪真实的一张，胜过十张完美摆拍。

川内倫子 Rinko Kawauchi · 1972–

拆的这张：《Illuminance》系列中的玫瑰——直闪 + 大幅过曝，花"烧"成一团发光的白，背景沉进深品红，梦幻得不真实。

🔍 拆解

  • 光线：机顶直闪 + 大幅过曝（+2EV 以上），主体亮到失去细节，变成"光本身"。
  • 色彩：品红/紫调，低饱和背景 + 高亮主体，梦境感。
  • 题材：她不只拍人——花、草、光斑这些"空镜"，是组图的呼吸口。
富士配方 · 川内式发光体

高光 −2（保住一点点细节）｜阴影 0｜色彩 +1

📍 清水湾复刻：大坑墩找一朵花、一片草叶、一只手——逆光 +1.5EV 过曝，拍"空镜"。回来和人物组图，你的相册会高级很多。

蜷川実花 Mika Ninagawa · 1972–

拆的这张：写真集封面——模特躺在浓烈红/品红花丛里，青绿点缀，色彩推到极限，肤色却依然通透，眼神直勾勾。

🔍 拆解

  • 光线：柔和均匀的漫射光（阴天/柔光），脸上无硬阴影——浓烈色彩 + 干净光线是她的不二法门。
  • 色彩：饱和拉满：红、品红、紫主导，青绿做对比色；肤色单独保住，不跟着一起"浓"。>
  • 情绪：直视镜头，浓颜系，梦境又清醒。

给新手的建议

  • 每个点只练3–4个 pose。 概念图①–⑥每张就是一个机位，拍透比拍多重要。
  • 让她动起来。 "往前走""玩头发""先看远再回头"——动态比摆拍自然十倍，快门连拍。
  • 你先示范。 把手机概念图举给她看，自己松弛地比划一下，尴尬减半。
  • 多夸，具体夸。 "这个回头特别好""风把裙子吹起来了完美"——模特放松了才有好表情。
  • 逆光记得给脸补曝光。 点测光对脸 +0.3～+0.7EV，不然脸黑一片。
  • 带的东西：水、防晒、草帽（道具）、小风扇、湿纸巾、拉链袋、充电宝。
