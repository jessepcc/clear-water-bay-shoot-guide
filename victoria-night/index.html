01 / START WITH THE FRAME

先让照片有一个动作

主场设在尖沙咀海滨，艺术馆外海滨 → 星光大道西段。把维港当色块、光点和叙事空间。

三张成组，人物不必一直看镜头

23mm / 开场人小一点，留一半天空或水面；停步、回头。
75mm / 情绪压缩灯光，近肩侧脸；一手理发，眼神先离开镜头。
23mm / 结尾倒影或慢门；一张清楚的人，一段流动的城。

按年轻成年女性设计：米白、淡蓝或低对比花纹连衣裙，或素色上衣配自己的外套。拍摄时先让身体转 30–45°、肩膀放松，再转眼睛；下巴轻向前，不用一味低头。口令：「理一下头发，停一秒」「往前走两步，再回头」。不需要另买道具。

面部骨骼、肤色和个人风格优先；不以族裔预设修脸或美白。服装与露肩程度由模特选择。

开拍前 · 90 秒
  • RAW + FINE JPEG；M 档；机械快门；单张拍摄。固定 ISO、固定 K 白平衡。飞灯先从 1/125s 开始；先把无线与普通同步打通，再研究 HSS。闪光不能靠电子快门默认工作。
  • 固定 ISO 让环境和闪光分开调。DR100 起步；D Range Priority 关。开着 Auto ISO 容易让你压暗环境的调整被相机抵消。
  • 人物停下：AF‑S 单点 + 眼检测。走动：AF‑C 区域 + 眼检测，但等她停顿再闪；单灯回电跟不上高速连拍。IBIS 开，仍需检查人物运动模糊。
  • 关闪光试一张背景 → 开闪光试一张肤色。D 设置 → 屏幕设置 → 手动模式曝光/白平衡预览，选 PREVIEW WB（仅预览白平衡），闪光前更易构图；回放看脸、高光与直方图。
  • 先用小裸灯近距离。大型柔光箱、远距离满功率与 HSS 都会压缩小灯余量。每闪一张看就绪提示；别连续满功率硬追动作。

飞灯，先解决谁拿这盏灯

X5 留在相机热靴，iT32 从它上面分离，自动转为 RX 接收。先确认模块标着 X5 F：F 是 Fujifilm，官方兼容表明确列出 X‑T5。首次操作见逐步教程。

只有摄影者和模特时：全身 / 双手自由 → 机顶灯；近距离 23mm → 摄影者手持灯；75mm 近脸 → 模特手持灯在画外。灯不可能悬浮在人旁边；远机位、自由双手和任意离机灯位无法同时得到。

23mm ≈ 35mm 等效

机顶灯拍环境半身 / 全身，约 2–4m，f/2.8 起。摄影者手持灯则缩到约 1–1.5m，拍胸像，脸放画面中央区域，避免边缘变形。

75mm ≈ 112.5mm 等效

胸像 / 半身约 4–6m。模特手持灯时从 f/4、ISO 200–400 起；灯离脸约 0.6m。很近的灯可能在最低功率仍太亮，不强求 f/1.2；远处港灯仍能虚化。

下列快门、ISO、功率、距离都是 estimate（估计起点），未在现场实拍。光圈不依赖镜头具体版本。

① 日落回眸 · 先拍自然光

23mm · f/41/125s 起ISO 125无片 / 5600K
时间
日落前约 60–20 分钟。优先自然侧逆光；靠近日落时再试近距补光。
站位
23mm 约 2–3m；身体向侧面，头回转。面对港岛取景，夕阳大致来自西边、画面右方；要把夕阳放身后须转向西南/西，并接受背景改变。
单灯
两手自由就用机顶灯，M 1/32 起、灯头朝前；补得不够先少量加功率。摄影者手持灯只适合缩至 1–1.5m 的胸像。自然光已好看就关灯。
口令
「往前两步，停住，回头看我；手轻碰裙边或衣角，不用提很高。」先侧身再回眼神，不强扭颈部。
曝光
背景太亮先收光圈；普通同步不能超过 1/250s。无需闪光时可用 1/500s 等更快快门。先保脸部高光，不为了白裙亮度把皮肤拍白。
参考
贺喜遥香：回眸与暖色。维港没有沙滩，改用海水和栏杆线条；太阳可能早被楼宇遮住。

② CTO 蓝港 · 暖肤与蓝天分开

23mm · f/2.81/125sISO 400–800Full CTO / 3200K
时间
日落前后到民用暮光结束；有天空层次时先完成，不能等全黑再造出蓝天。
拿灯
近距离胸像：摄影者左手拿灯、右手持相机；机位距人 1–1.5m，灯偏出 40–60cm，稍高于眼，朝脸。约前侧 20–30°，不是凭空放在 45°。
功率
Full CTO，M 1/128 起，脸暗再升至 1/64、1/32。全身/三米环境构图改为机顶灯，约 1/32 起，以回放调整。
口令
「肩膀转开一点，手指轻碰衣领；看海面，停一下，再只转眼睛看我。」确保灯和手留在画外。
曝光
先关灯压好海天，再开灯只调脸。背景暗可 1/125 → 1/60s 或升 ISO；ISO 翻倍时试把灯降一档。
参考
金川纱耶：冷水面、暖脸与近处手势。原图偏紫且经过处理；Full CTO + 3200K 是更蓝的创作变体。

③ 长焦灯点 · 模特拿灯，相机退远

75mm · f/41/125s 起ISO 200–400½ CTO / 4000K
时间
蓝调后半段，城市灯开始明显时；实际点灯、雾霾与招牌色以当晚为准。
拿灯
相机离人约 4–6m，紧凑近肩/头部画框。模特外侧手拿灯，在脸前侧约 0.6m、略高于眼；只用另一手理发。先检查灯、手、手臂是否入镜。
功率
最低 M 1/128 起。若仍太亮，灯远移或 f/4 → f/5.6、ISO 400 → 200；不要坚持 f/1.2。快门按背景可降到 1/60s，提醒她停住。
口令
「头轻靠向空着的手，肩膀放松，先看我旁边，再看镜头。」灯位固定，脸只小幅转动，避免阴影忽然跨过眼睛。
背景
75mm 先挑远处一小块楼宇灯点，避开亮点贴眼睛或头顶。大散景要靠背景远、画框紧；不是只靠最大光圈。
参考
梅泽美波：头倾与手理发。无法把灯藏出半身画框就改紧裁切；双手自由的全身回到机顶灯。

④ 双层倒影 · 不另带反光工具

23mm · f/2.81/60sISO 400–800½ CTO / 4000K
条件
只用现场已有的干净玻璃或小水洼；没有就拍栏杆线条与负空间。当天不一定有可用反射，不制造水洼。
拿灯
先用机顶灯、人物约 2m，M 1/32 起；反射面出现白色闪光斑时改角度。近距摄影者手持灯可偏离镜面反射方向。
构图
脸落在清楚的一层，反射只占下方或侧面约三分之一。相机靠近反射面但不把镜头触上去。
口令
「身体侧一点，手碰袖口；视线落在水面，再慢慢抬眼。」让她停住而不是同时摆动。
检查
不开灯看反射，开灯再看白斑和自己的倒影。不要为了低机位跨栏杆或堵人流。没有同条件真人参考，此组是构图实验，颜色沿用 C2。

⑤ 慢门流光 · 先机顶，双手稳定持机

23mm · f/41/8–1/15sISO 200–400Full CTO / 3200K
拿灯
iT32 接回 X5，机顶正向灯；相机约 2m。用双手持相机，避免一手拿灯、一手同时转动相机。M 1/64 起，按回放调整。
准备
选脸前环境光较弱的位置。先关灯重新设背景；1/8s 比 1/125s 多记约 4 档环境光，不能直接沿用之前的 ISO/光圈。
动作
「保持脸不动，看着这里。」前帘闪光亮起后，在本次曝光里做小幅水平转动；第一张完全不转作基准，之后每次只增加一点幅度。
同步
先前帘；可选后帘的官方操作见 首次用灯。后帘把闪光放在末尾，仍需控制脸部环境曝光。
检查
环境光已在曝光中记录到脸，就会有重影。先移离路灯或降低 ISO/收光圈，再相应补闪光；失败几张就回 1/125s 收清楚照片。沿用 C1 色彩，慢门是实验，不是原图摄影师设置。

⑥ 侧脸明暗 · 一盏灯拍出方向

75mm · f/41/125s 起ISO 200–400Full CTO / 3200K
拿灯
延续模特手持，灯在脸前侧约 45°、约 0.6m、稍高于眼，M 1/128 起。机位 4–6m，紧凑近肩构图；让拿灯的一侧肩和手尽量出画。
口令
「身体侧开，脸缓慢转向灯一点；停在近眼还有光的位置。」露出两眼或完整侧脸，避免鼻尖与远侧脸粘成一条线。
调整
鼻影太长：灯向正前移一点；眼窝黑：降低灯位。皮肤亮面太强先减功率/拉开灯距，最低档仍亮就收光圈或降 ISO。
单灯
前侧灯做主光，暗侧靠环境留轮廓。本套器材没有人在身后拿灯，不能同时安排独立前主光与发丝轮廓光。
参考
从 今田美樱 的身体转角与清楚近眼开始，再让影子稍深；先以舒服的表情为准，不为模仿姿态硬压头颈。

02 / YOUR FIRST FLASH SESSION

第一次用 iT32 + X5，照着做

仅用现有器材。以下按官方 iT32 说明书及 X‑T5 菜单核验；功率和曝光仍需试拍。相机 M 与闪光 M 是两件事。

① 出门前：充电、辨认模块

  1. 检查 X5 的型号是 X5 F。F 才是富士版；说明书兼容组 A 包含 X‑T5。你已确认有 X5，系统后缀仍要看实物。
  2. X5 磁吸贴合 iT32 底部，再为 iT32 接 USB‑C 充电。X5 通过贴在灯上充电；不是另找一个 X5 USB‑C 孔。先在家充好两个电池。
  3. 认识三个附件：1/1 橙片 = Full CTO；1/2 橙片 = ½ CTO；透明/乳白小罩 = 盒内柔光罩。先只用一片 CTO；无需叠片、灯架或柔光箱。

② 先在机顶打出第一张

  1. 相机、闪光都关闭。X5 贴在灯底，按锁环标示松开 → 热靴滑到底 → 锁紧。不要硬拧或半插。
  2. 长按 iT32 闪电/电源键。屏幕出现解锁提示后，按提示滑动或转旋钮；须在约 6 秒内解锁，否则自动关机。
  3. 灯下滑菜单：无线设 Wi‑Off，TTL/M/Multi 选 M。回功率页面，用屏幕 −/+ 或旋钮设 1/128。首次先低功率，只证明它能闪。
  4. X‑T5：M 曝光、机械快门、单张；23mm，1/125s、f/2.8、ISO 400，WB 4000K，灯上装 ½ CTO。F 闪光设置 → 闪光功能设置，确认外接热靴闪光可用，同步选 1ST CURTAIN / 前帘。关闭电子快门、静音模式。
  5. 距模特约 2m，灯头直朝前，拍一张。脸太暗就逐档加功率：1/128 → 1/64 → 1/32 → 1/16；脸太亮就反向调。这是估计起点，以回放为准。

相机 M 固定快门/光圈/ISO；灯的 M 固定闪光输出。若灯还显示 TTL，你的曝光虽手动，闪光仍会自动改变。机顶 TTL 可以以后用于走动抓拍，今天先用 M 理解每个调整。

③ 拆开，就是飞灯

  1. 先关设备再拆装。iT32 长按电源关闭；X5 长按 −/电池键，显示电量后关闭。把 iT32 从磁吸 X5 上取下，X5 留在相机热靴；iT32 自动切为 RX 接收模式。再开灯、开相机；按任意 X5 键唤醒引闪端。
  2. 长按 X5 的 +/M 键切到 M：橙色表示手动，绿色表示 TTL。连接相机后常亮；闪烁表示未连接，先查热靴插紧和触点。
  3. 短按 X5 的 +/M 或 −/电池键调输出；每次 1/3 档，通常按 3 次是一档。例如 1/64 → 1/32 是加一档、能量加倍，数字分母变小。
  4. 摄影者或模特拿住 iT32，朝脸，按相机快门试拍。自己的 X5 与 iT32 组合按说明书自动分体接收，不需要照搬 X3/XPro 的手动配对流程，也不用 S1/S2 光引闪。
  5. 先拍 1/125s 无黑带的一张，再用 X5 降一档功率拍第二张；脸确实变暗，才算无线触发和遥控都通过。

测试键在灯身，X5 没有独立 TEST 键。灯身试闪只证明闪光本体能工作；真正的无线测试是按相机快门。X5 灯不亮时按键唤醒，相机本身无法唤醒休眠的 X5。

④ 只有两个人，怎样拿灯

拿法怎么做适合 / 限制
A · 机顶iT32 接回 X5；灯头朝前。约 2m，M 1/32 起，按脸调整。23mm 环境 / 全身；模特双手自由。正面硬光要靠身体转角、服装与构图增加层次。
B · 摄影者拿灯右手持相机，左手把灯伸出约 40–60cm，略高于眼；相机距人 1–1.5m，灯约在脸前侧 20–30°。23mm 胸像，M 1/128 起；先站稳单张拍。远到 3m 就只有小偏轴角度，不会自动变成 45° 侧光。
C · 模特拿灯让她用外侧手拿灯，在脸前侧约 0.6m、略高于眼，灯头朝脸；手和灯移到紧凑画框外。75mm 近肩 / 头部特写，相机 4–6m；M 1/128、f/4、ISO 200–400 起。另一手才可理发；不能同时复刻双手自由的姿态。

最低 1/128 仍过亮：先把灯拿远一点；不够就 ISO 400 → 200，或 f/2.8 → f/4。背景也会变暗，再用较慢快门或改时段补环境。很近的灯与大光圈有冲突，不要先买附件解决。

真正入夜，75mm 背景太暗：模特手持灯可先试 1/60 → 1/30s，让她停住并放大检查近眼。若要升 ISO，但闪光已在最低功率、灯也拿不远，就把灯接回机顶：75mm、f/2.8、ISO 800、1/60s、½ CTO / 4000K，机位约 4m，M 1/32 起再按脸调整。这是估计起点；机顶换来更大的曝光余量和双手自由，光向也变得更正面。

灯头朝脸，不朝天空；不要让握灯的手遮住发光面。模特觉得刺眼就调整方向、暂停。要让双手自由又有近距离 45° 灯位，需要第三个人拿灯；本计划的基本拍法不依赖第三个人。

⑤ CTO 与盒内柔光罩怎么用

按盒内卡位方向把 1/1 或 1/2 橙片装到灯头，让发光面完整通过滤片；拍一张无片、一张有片，看光是否明显变暖。装不上时查看官方安装图，不自行剪片或强塞。

先裸灯 + CTO 拍好。想试柔光罩，按说明书方向插到灯头、卡紧，再检查 CTO 有无松动/遮挡，重拍同一姿态。若实物附件不能牢靠共装，就只保留 CTO。小罩主要把光散开，海滨没有天花板可反弹，它不会变成柔光箱。光散掉后脸可能更暗，只按回放补功率；没见到改善就取下。

柔和程度更取决于灯在人物看来有多大。小灯移近、让鼻影较短、减少脸与灯的角度，可以改善观感；仍会有清楚的硬影。

HSS、后帘、造型灯：第一次是否需要？

先不用 HSS：X‑T5 普通同步为 1/250s 或更慢；本页 1/125s 留余量。iT32 + X5 F 支持 HSS，但需从相机设置，高速同步最低功率为 1/16，余量也会减少。下午背景太亮，优先自然光或收光圈，不急着开 HSS。

慢门先用前帘。之后可在 F 闪光功能设置 → 同步选 2ND CURTAIN / 后帘，拍 1/8s 测试；这是闪光在曝光末尾发光，不能自动去掉脸的重影。

造型灯只用来观察影子或辅助找焦点。亮度不是闪光曝光预览；调好灯位后关掉，避免额外的脸部混合光。

03 / COLOUR IS LIGHT

CTO：把肤色和环境分开

飞灯决定阴影方向；滤片与固定 WB 决定两种光的色差。CTO 装在灯上，不装镜头。

暖闪光灯 + CTO+低 K 白平衡匹配暖闪光=蓝环境人物接近中性

CTO 把闪光变暖；低 Kelvin WB 把这束暖光校回接近正常肤色，同时把未加滤片的海天推向冷蓝。升高 K 值会整体变暖，降低 K 值会整体变冷。必须让闪光真正照到脸；只降低 WB，脸也会蓝。

五张测试，找出你这盏灯的蓝

  1. 不开闪光，用 5600K 拍背景基准。
  2. 固定曝光，换 3200K；看海天是否保留蓝色渐层。
  3. 开无片闪光：人物容易偏蓝，这张只是对照。
  4. 装 Full CTO，保持 3200K；让闪光主导脸部。
  5. 脸太橙：把 K 值小幅降低；脸太蓝：小幅提高并检查光是否打到脸。同一组光线确定后锁 WB。

不用买灰卡：固定模特位置，同一张脸比较无灯 / 有灯，有素色浅衣服可同时观察，但衣服不等于校准灰卡。肤色一侧蓝、一侧橙时，先移开路灯、调灯位与比例；一个 WB 无法单独修好两种光。

只改一个变量：普通同步范围内，背景亮度 → 快门；脸部闪光亮度 → 功率 / 灯距；背景颜色 → WB；肤色颜色 → CTO 与 WB 配对。光圈、ISO 同时影响两者；慢门也会增加脸的环境光。

左手拿灯，近距离才有角度

怎么用：偏出镜头轴线会改变鼻影；灯只高一点，避免眼窝变黑。站远后同样的手臂伸出距离只能得到很小侧角。

做不到：不能一边在三米远全身构图，一边自己把灯放到人物一米旁边；全身改机顶灯。

DR、黑位、肤色：菜单的边界

DR100 便于固定 ISO 和理解闪光。招牌高光确有需要，可试 DR200（ISO ≥250）或 DR400（ISO ≥500），随后重测闪光。D Range Priority 关，才可自由调 Tone Curve；已剪切高光不能复原。

Shadows −1/−2 软化阴影曲线，不把纯黑抬成胶片扫描的灰。配方也不能独立调暖脸/冷背景、生成光晕或大散景；先靠 CTO、WB、灯距和取景解决。Clarity 0 让机内处理更快。

09 / FIX ONE THING

第一次卡住，按这个顺序排错

症状先做什么
灯开机又立刻关长按电源后按提示解锁；不要等过 6 秒。
X5 指示灯不亮按任意 X5 键唤醒；相机不能唤醒它。若红色慢闪，先充电。
X5 橙/绿灯闪烁未连接相机：先关机、热靴重新插到底并锁紧，再开机。橙常亮为 M，绿常亮为 TTL。
灯身试闪有效，相机不闪检查 X5 F、机械快门/非静音、灯已 RX 且就绪；让 X5 与灯重新磁吸贴合再分离，按快门复测。自己的分体组合先不用手工乱改频道/ID。
画面黑带先回机械 1/125s、前帘；普通同步别超过 1/250s，检查热靴与就绪。仍有问题先机顶验证。
脸白，背景正常减闪光；最低 1/128 仍白，灯远移或降低 ISO/收光圈，背景再用快门调整。
脸正常，背景黑静态 1/125 → 1/60s，提醒模特停住；或升 ISO 并相应降闪光。天已无层次就拍灯点，不继续造蓝天。
脸和背景都蓝查 CTO 装好、闪光真的照脸；比较无灯/有灯。再微调 K，不先把整个画面暖回去。
半边蓝、半边橙移离路灯，减小脸部环境光，改灯方向；一个 WB 修不了两束不同光。
柔光罩后更暗，影子仍硬取下小罩比较；它在海滨不会变成大光源。重拍同一距离再决定是否保留。
慢门鬼影 / 75mm 虚焦慢门先减脸前环境光、小幅转机；75mm 近眼对焦、f/4、等停顿。必要时回 1/125s。

只带你现有的东西

  • X‑T5、23mm、75mm，相机内已有电池与存储卡，出门前充好。
  • 一盏 iT32 + X5 F，出门前一起充好、确认相机能引闪。
  • 盒内 Full CTO、½ CTO、小柔光罩；不要求其他灯具或支撑。
  • 23mm 回眸开场、CTO 胸像、75mm 灯点近脸各一组。
  • 条件成立再拍倒影 / 慢门，最后留一张清楚收尾。

模特拿灯前先示范方向；摄影者拿灯时先站稳，换镜头先把灯接回模块或交给模特拿好。保持公共通道畅通，雨水或海浪喷雾时先收闪光。
